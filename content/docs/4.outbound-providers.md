title: Outbound providers
description: Configure SMTP or an email API without exposing credentials in environment variables.
---

## Configure delivery

Administrators open **Outbound**, select SMTP, Resend, SendGrid, Mailchimp, or Postal, and enter provider settings. Secrets are encrypted before storage and are never returned by the API.

Saving creates an immutable revision. New messages pin that revision; queued retries continue using the credentials selected when they were accepted.

## Verify safely

1. Save and activate the provider.
2. Select **Test connection**.
3. Select **Send test to me**.
4. Confirm the message reaches `sent` in **Emails**.

## SMTP guidance

Use port `465` for implicit TLS or `587` for submission according to your server. Use a dedicated sending account with the minimum required privileges. Do not reuse an administrator mailbox password.

## Changing credentials

Leave a secret field blank to retain the current secret for the same provider. Switching providers requires that provider's credential. Never place provider credentials in application `.env` variables.
