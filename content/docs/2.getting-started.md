## Sign in

Open the dashboard login page and enter an approved email address. A six-digit, one-time code expires after five minutes and locks after repeated failures.

Never share a login code. Support staff do not need it.

## Get an API key

Open **API Keys** and request a key for your approved address. The key is delivered by email and shown only there. Store it in a secret manager and send it through the `Authorization` header.

## Check service readiness

Operators can inspect **Overview**, **Emails**, and **Queue**. Administrators can use **Outbound** to test the active provider. A queued response means the message was accepted for processing, not that the recipient provider accepted delivery.
