## Start here

This handbook describes the supported dashboard and API workflows. Provider credentials, encryption keys, and infrastructure secrets must never be pasted into tickets, logs, webhook payloads, or documentation.

1. Read [Getting started](/dashboard/docs/getting-started).
2. Ask an administrator to configure [outbound delivery](/dashboard/docs/outbound-providers).
3. Request an API key and follow [Sending email](/dashboard/docs/sending-email).
4. Administrators can configure [inbound webhooks](/dashboard/docs/inbound-webhooks).

## Roles

| Role | Access |
| --- | --- |
| Viewer | Own API keys and documentation |
| Operator | Viewer access plus delivery status and queue monitoring |
| Admin | Provider, inbound, integration, and member operations |
| Owner | Admin access plus access-policy management |

> Access is enforced by the server. Hiding a dashboard link is not an authorization control.
